기술블로그 레퍼런스

nbuntu 테마를 발전시키기 위한 외부 레퍼런스.
레트로 갠홈 감성 + 터미널/개발자 블로그 + 픽셀 폰트의 교집합을 찾았습니다.
기존 나루 내부 레퍼런스(duboo, hamkki, hihihirobot)와 다른 방향의 영감을 줄 수 있는 사이트들.
기존 나루 레퍼런스: duboo.naru.pub (파스텔 2단) / hamkki.naru.pub (동숲 테마, 메인 레퍼) / hihihirobot.naru.pub (Win98)
01 localghost.dev
https://localghost.dev
nbh 갠홈과 가장 유사한 방향
Sophie Koonin의 개발자 블로그. 레트로 갠홈 + 개발 블로그의 완벽한 조합. 1999, 2003, vaporwave, garden 등 7개 테마 전환 기능이 있음. 웹링(Webring) 참여, animated GIF 구분선, 마키(marquee), 커서 트레일 등 올드웹 요소를 현대적 접근성과 결합. "갠홈에서 개발 글을 쓴다"는 nbh의 컨셉과 정확히 일치하는 레퍼런스.
레트로 갠홈 멀티 테마 웹링 Eleventy 접근성

02 petrapixel.neocities.org
https://petrapixel.neocities.org
갠홈 꾸미기 리소스 보물창고
Neocities 대표 갠홈. 2단 레이아웃 + 픽셀아트 + 88x31 버튼월. 다크/라이트 토글, 블링키(blinkie), animated GIF 구분선 등 올드웹 장식 요소를 풍부하게 활용. 갠홈 코딩 도움말과 리소스를 제공하는 사이트이기도 함. nbh 갠홈의 배경 패턴, 88x31 배너 교환, 시즌 이펙트 등 로드맵 아이템에 직접적 영감.
Neocities 2단 레이아웃 픽셀아트 88x31 버튼 블링키

03 sadgrl.online
https://sadgrl.online
갠홈 제작 도구 + 올드웹 리소스
올드웹 감성 갠홈 제작의 허브. 레이아웃 빌더로 반응형 갠홈 HTML/CSS를 자동 생성해주고, Neocities/갠홈 초보자를 위한 HTML·CSS 가이드와 CodePen 데모(호버 애니메이션, 레이아웃 트릭, JS 효과) 제공. 방명록(guestbook) 기능도 있어 nbh 갠홈의 방명록 UI 참고 가능. 갠홈 꾸미기에 바로 쓸 수 있는 실용적 리소스가 핵심.
레이아웃 빌더 갠홈 가이드 CodePen 데모 방명록 올드웹

04 naruter.naru.pub
https://naruter.naru.pub
나루 생태계 구조 참고
나루 공식 갠홈 템플릿. 두 가지 레이아웃 제공: A안(풀스크린 + 좌측 네비) / B안(제한 폭 + 상단 네비). 나루 환경에서 동작하는 갠홈의 기본 구조와 파일 구성을 참고할 수 있음. 오픈소스(GitHub 공개)로 코드를 직접 뜯어볼 수 있다는 점이 장점. 현재 nbh 갠홈은 B안(900px 제한 + 상단 네비)과 유사한 구조.
나루 템플릿 오픈소스 2가지 레이아웃 기본 구조

05 retroweird (Eleventy 테마)
github.com/brennanbrown/retroweird
레트로 블로그 구조/위젯 참고
GeoCities, MySpace, AngelFire에서 영감받은 레트로 블로그 테마. 6가지 프리빌트 테마(Default, Vaporwave, GeoCities, MySpace, Brutalist, Academia). 88x31 배지월, 모듈형 위젯 시스템(시계, 방문자 카운터, 날씨 등). nbh 갠홈 로드맵에 있는 위젯(달력, 방문자 카운터, 배너 교환)의 구현 방식을 참고하기 좋음.

01 Tin Can Knits
https://blog.tincanknits.com
뜨개 공방 테마의 직접적 레퍼런스
캐나다 디자이너 듀오의 뜨개질 패턴 블로그. "joyful seamless knitting patterns". 카드형 그리드 레이아웃에 완성된 작품 사진이 주인공. 어스톤(earth tone) + Cabin 폰트의 따뜻한 조합. "deliciously textured", "vest of my dreams" 같은 감성적 카피라이팅. nbh 뜨개 공방의 글 목록 레이아웃과 톤에 직접 참고 가능.
뜨개질 블로그 카드 그리드 어스톤 작품 사진

02 Life Is Cozy
https://lifeiscozy.com
"코지"라는 단어의 웹 디자인 구현
"A lot about CRAFting. Everything about cozy". 패턴, 스티치, 재료 섹션으로 구성된 핸드크래프트 블로그. 넉넉한 여백 + 따뜻한 사진 + 인스타그램 갤러리 연동. "You are welcome here" 메시지로 포용적 커뮤니티 분위기. nbh 뜨개 공방의 "한 코 한 코, 따뜻하게" 감성과 일맥상통.

03 Maggie Appleton
https://maggieappleton.com
디지털 가든 + 따뜻한 컬러 시스템
"지적인 아늑함(intellectual coziness)"의 대표 사이트. 크림색 배경 + 크림슨 악센트 + 시블루 하이라이트. 에세이/노트/패턴/라이브러리로 나뉜 "디지털 가든" 구조. 세리프 헤딩과 넉넉한 여백이 인쇄물 같은 에디토리얼 감성. 뜨개 공방의 Gowun Dodum 폰트 + 코랄 악센트 방향과 유사한 따뜻한 디자인 시스템.
디지털 가든 크림+크림슨 에디토리얼 일러스트

04 Rach Smith
https://rachsmith.com
개인 공간 + 놀이 요소
레인보우 컬러 시스템의 디지털 가든. 빨강~보라 순환하는 악센트 컬러. 다크 모드, 레인보우 테마, 커서 트레일 등 방문자 커스텀 옵션. 2017년부터 이어온 개인 일기장 같은 친밀감. 모노스페이스 폰트 + 리스트 기반 심플 구조. nbh 갠홈의 "숨겨진 게 있을지도?" 이스터에그 감성과 통하는 놀이 요소.

https://cozybluehandmade.com
